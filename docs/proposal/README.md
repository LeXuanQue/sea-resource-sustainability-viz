# Proposal

The submitted PDF was typeset in Google Docs; this script builds an earlier draft layout.

- `proposal.pdf` — the submitted file: 4 text pages (Google Docs) + 6 prototype sketch pages.
- `proposal.docx` — the same text, editable.
- `proposal.md` — the proposal text in Markdown, kept in sync with the submitted version.
- `build_pdf.py` — earlier draft build pipeline (Markdown + Chromium), retained for reference.
